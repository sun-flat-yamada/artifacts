## 🎯 Purpose

- Maintain a **curated** set of reliable artifacts

## 📁 Repository Structure

The repository is organized to ensure clarity and long‑term maintainability:

- `contents/` — Collected information
- `assets/` — General-purpose reusable assets  
- `scripts/` — Utility scripts supporting personal workflows  
- `configs/` — Stable configuration files and templates  
- `docs/` — Documentation, references, and usage notes  
- `archive/` — Older artifacts retained for historical continuity  

---

## 📌 Artifact Criteria

Artifacts included in this repository must meet the following:

- **Stable** — No longer experimental  
- **Reusable** — Valuable across multiple contexts  
- **Documented** — Includes minimal usage notes if necessary  
- **Curated** — Selected intentionally, not accumulated casually
